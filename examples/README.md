# Examples

Prompts to try once the server is installed:

- "Track the Amazon product B09DFCB66S and tell me its price history."
- "How many Asin credits do I have left?"

Inspect the tools without an AI client:

```sh
export ASIN_API_KEY="YOUR_API_KEY"
npx @modelcontextprotocol/inspector npx -y @asindev/mcp
```
